# Portfolio – Aicha Menif

Ouvrir le dossier dans VS Code (Fichier > Ouvrir un dossier), puis ouvrir `index.html`
avec l'extension **Live Server** (clic droit > Open with Live Server).

## À faire avant la mise en ligne
1. Remplacer `https://VOTRE-DOMAINE.tn/` par ton vrai domaine dans : index.html (canonical, og:url, og:image, JSON-LD), robots.txt, sitemap.xml
2. Vérifier l'URL LinkedIn `https://www.linkedin.com/in/aicha-mnif` (index.html, 3 occurrences + JSON-LD)
3. Déclarer le site dans Google Search Console et envoyer sitemap.xml
4. Créer/mettre à jour la fiche Google Business Profile / profils LinkedIn avec le même nom et la même ville (Tunis) pour renforcer le SEO local (GEO)
